# Optional PRL MetaMask experiment

Experimental, unintegrated source. The primary PRL wallet connects directly to Ledger and does not require MetaMask or this package.

This package preserves the tested custom-RPC/Snap boundary and a separate-origin developer demo. It is not published or physically validated. Do not use valuable funds.

See [scope, API, permissions, recovery requirements, and verification limits](../../docs/metamask-integration.md).
