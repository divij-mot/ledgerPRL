# Pearl Ledger APDU protocol

The canonical, versioned specification is [Protocol v1](protocol-v1.md). It defines the APDU encoding, command and status tables, chunked upload/signature lifecycle, network/path policy and transaction serialization. This entry point follows Ledger's documentation naming convention without maintaining a second protocol copy.

See [native app build and validation](firmware.md) for the device adapter, trusted review, lifecycle handling, tested limits and remaining release gates. Installation-manager APDUs generated by the offline packager are separate from this application protocol.
