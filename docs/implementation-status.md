# Implementation and verification status

Development checkpoint, 2026-10-10. This is conventional Ledger seed custody software, not an audited or vendor-approved release. Limited Nano S Plus emulator and physical tests passed; no funded transaction, live discovery or confirmation is qualified. The current device application is the [Ledger Bitcoin-based C port](../apps/ledger-bitcoin-prl/README.md); the previous Rust device application and its qualification records are historical reference only. See [current feature coverage](prl-feature-coverage.md#current-desktoplite-parity) and [mainnet testing](mainnet-testing.md).

## Implemented software

- Restricted Ledger Bitcoin 2.5.1 C adaptation with PRL network/monetary policy, committed PSBT validation, BIP86 ownership/change checks and Ledger SDK BIP32/BIP340 signing after trusted review
- Exact bigint TypeScript PSBT adapter, independent signature verification, transaction finalization and CLI
- Standalone seedless DMK/WebHID wallet website, browser-side public-account discovery/validation, a fixed-endpoint same-origin indexer proxy and an optional local authenticated node bridge
- Explicit Ledger Wallet Live App entry using Wallet API transport and source-adapted Ledger Wallet 4.23 views; both entries share the same PRL wallet and signing checks
- Public/full watch-only backups, durable payment reservations and signed-byte recovery, bounded stored-journal validation, atomic merge-on-success, optional watch-cache deletion and account-context form reset
- Cross-language fixtures, pinned actual Pearl script-engine oracle and bounded independent software/source reviews; the optional MetaMask experiment is outside the direct website flow

## Ongoing and external gates

Ledger’s current new-app Rust requirement leaves this separate-chain C fork’s publication route unresolved. The documented Bitcoin clone route is Layer-2-specific; no PRL exception has been established. See the [official distribution requirements review](../tools/ledger-distribution-review/README.md) and [conditional release-path recommendation](../tools/ledger-release-path-review/README.md). No vendor classification, architecture switch or submission has occurred.

The previous Rust application's 25 artifacts/packages were independently reproduced byte-for-byte under its [canonical logical-path build recipe](../tools/build-reproducibility/README.md); this is not C-port reproducibility evidence. Full C-port build/package reproducibility and complete native qualification of the continuation-validation and post-approval callback source corrections remain open beyond the limited Nano S Plus replay above. Each historical ELF keeps its own evidence; results cannot be combined into qualification of a later artifact.

Beyond the single Nano S Plus OS 1.7.0 smoke test, retail device/OS coverage, physical P2MR review, restore, fault behavior and worst-case resource/16-input measurements remain unqualified. Complete loaded-browser/import/cross-tab/interruption coverage, public TLS deployment, fresh live-indexer compatibility, exact-published-commit CI for each subsequent change, independent human/dependency review, Ledger functional/distribution review, production packaging and project licensing remain release gates. The physical installation used the existing seed and OS; no seed reset, firmware update or mainnet broadcast was performed.

Passing emulator tests does not imply hardware equivalence or guarantee Bitcoin-app security parity. The host trusts a selected backend's chain view; it is not an independent Pearl SPV proof verifier. XMSS/PQ-only signing remains outside this version.
