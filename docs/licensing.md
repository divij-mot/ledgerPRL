# Licensing status

The owner has not selected a license for newly authored project code. Packages are private/nonpublishable. No blanket open-source license grant is made here.

Third-party code retains its own licenses and notices. The pinned Ledger Rust SDK and secure SDK are fetched separately by the preparation script; their existing license/copyright files must remain intact. The tracked SDK patch and any copied material must be reviewed against the relevant upstream license before distribution. Rust/npm/Go dependency licenses must be inventoried and reviewed before release.
